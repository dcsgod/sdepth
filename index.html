Pattern Recognition Rule Sliding Window → array/string, contiguous subarray. Two Pointers → sorted, searching pairs. Fast/Slow pointer → cycle detection, midpoint. BFS → shortest path, level order. DFS + Backtracking → all combinations, paths. DP → overlapping subproblems + optimal substructure. Greedy → local optimal = global optimal (prove it). Heap → streaming top-K, median.
